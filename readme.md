# IT Risk & Cybersecurity Assessment – Portfolio Case Study

## Project Overview

This is a self-initiated IT Risk and Cybersecurity Assessment case study developed to demonstrate practical understanding of IT risk management, IT General Controls (ITGC), control testing, audit documentation, and remediation tracking.

The project uses a fictional organisation and illustrative scenarios to demonstrate how an IT risk and cybersecurity assessment can be structured and documented.

## Project Objectives

- Identify and document common IT and cybersecurity risks.
- Understand and assess IT General Controls (ITGC).
- Design control-testing procedures and identify required evidence.
- Document potential audit findings and their business impact.
- Recommend corrective actions and track remediation.
- Present assessment observations in an executive-friendly format.
